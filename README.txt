# Modelado y Clasificación de Patrones Rítmicos de Batería

Este repositorio contiene la aplicación interactiva desarrollada en **Streamlit** para la revisión sistemática sobre el uso de Ciencia de Datos en el análisis de percusión musical.

## 🚀 Descripción del Proyecto
El proyecto analiza cómo las técnicas de *Machine Learning* y *Deep Learning* permiten transformar señales de audio de batería en características cuantificables. La aplicación sirve como interfaz visual para presentar los hallazgos de 8 artículos científicos clave identificados mediante la metodología PRISMA.

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Python 3.9+
* **Framework Web:** Streamlit
* **Manipulación de Datos:** Pandas
* **Visualización:** Bar Charts nativos de Streamlit
